The page you're reading is a fake terminal that ships as about 7 KB of real HTML, under 3 KB gzipped on the wire.

No frameworks on the wire, no web fonts, no trackers. Astro compiles everything to static pages, one small script runs the prompt, and CSS does the CRT impression: scanlines, glow, and the refresh band rolling up every few seconds. Every page also has a plain twin under [/plain](/plain), paper and serif, zero JS, including this post.

The whole build is eleven pages and about 55 KB of HTML. The dist directory totals ~130 KB, and more than half of that is the résumé PDF.

Posts are markdown files in a git repo. This is the first one.

```
$ cat stack.txt
astro · static html · one tiny script · css pretending to be a crt
```
